## 반복과 연결의 경계

- 월 반복은 최초 기준 일자를 유지한다. 해당 일자가 없는 달은 그달 마지막 날로 조정한다.
- 완료 취소는 이미 생성된 다음 회차를 삭제하지 않는다. 같은 회차를 다시 완료해도 다음 회차를 중복 생성하지 않는다.
- 다음 회차가 생성된 뒤에는 기존 반복 규칙 변경을 막는다. 삭제된 다음 회차도 임의로 복구하지 않는다.
- 다음 회차의 하위 체크리스트는 미완료 상태로 시작한다.
- 프로젝트와 연결된 작업에는 반복 규칙을 설정하지 않는다.
- 기존 완료 기록 중 완료 시각이 없는 항목은 날짜 미상으로 유지한다.
- 동시 편집의 기본 충돌 정책은 기존 Last Write Wins이며, 편집 양식은 변경된 원본과 저장되지 않은 초안을 감지한다.
